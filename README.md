# NashHash

**Autonomy needs boundaries. Trust needs proof.**

NashHash is an independent AI research and engineering studio developing trust infrastructure for autonomous AI agents.

Our focus spans:

- **Local-first personal AI:** lightweight personal agents designed for resource-constrained smartphones, with optional cloud reasoning.
- **Agent identity and provenance:** cryptographic key continuity, signed messages, and independently checkable evidence of agent interactions.
- **Safe delegation:** explicit authority, scoped permissions, reviewable actions, and revocation.
- **Engineering services:** commissioned agent infrastructure, trust and protocol design, integrations, evaluations, and support.

## Research status

| Workstream | Current status |
| --- | --- |
| Local-first personal agent | In development; Claude API integration is planned, not claimed as live |
| Agent key-continuity protocol | Research prototype v0.2, using a signed-nonce key-possession challenge |
| Signed public-post marker | Specification v0.1 |
| Trust receipt | v0.3 under design |

These are descriptions of ongoing research; they are not assertions that the projects are production-ready or independently audited.

A cryptographic signature can establish control of a key, but it does not by itself establish real-world identity, intent, safety, or legal authority. Technical “agreements” and authorization records do not replace legally enforceable contracts.
